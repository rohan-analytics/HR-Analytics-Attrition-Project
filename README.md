# HR Analytics & Employee Attrition Dashboard

Project Overview
This project analyzes employee attrition data using SQL and Power BI to identify key factors affecting employee turnover.

Tools Used
- SQL (MySQL)
- Power BI
- Excel

Key Insights
- Overall attrition rate is around 16%
- Higher attrition in Sales and R&D departments
- Low salary employees have higher attrition
- Overtime and low job satisfaction impact attrition

Dashboard Features
- Attrition KPI metrics
- Department and job role analysis
- Salary and overtime impact
- Interactive filters and employee details page

Files Included
- Dataset
- SQL queries
- Power BI dashboard
- Project report
- Dashboard screenshots
